# Quantum Computation & Complexity

Ayush Garg’s undergraduate complexity theory final project. The website currently contains the title and proposed outline; full content will be added later.

## Editing

- Edit `index.html` to change the title, outline, or content. Each planned chapter has its own labeled `<section>`. Add paragraphs, images, or links inside that section as the project develops.
- Edit `styles.css` to change the appearance. Colors are defined at the top.
- Put future images in an `images/` folder and use relative paths such as `images/circuit.svg`.

No dependencies or build step are required. Open `index.html` in your browser to preview it.

## GitHub Pages

Push these files to the repository’s `main` branch. In the GitHub repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, and click **Save**.

Once GitHub Pages finishes publishing, the expected public URL is:

https://arcanine1.github.io/Ayush-Garg-UCT-Final.github.io/

This is a project repository, so its repository name is part of the URL. Verify that the page loads publicly before submitting that URL in Panda Notes. Future pushes to `main` will update the site automatically after Pages is enabled.
