  1. Quantum Turing machines

    A classical configuration records the internal state, tape contents, and head position. A quantum Turing machine (QTM) uses these same configurations as basis states. One transition updates the amplitudes of all configurations coherently.

    Definition (Quantum Turing machine). Write $M=(Q,\Sigma,\Gamma,\delta,q_0,q_{\rm acc},q_{\rm rej})$. Here QQ is a finite nonempty set of states, Σ\Sigma is a finite nonempty input alphabet excluding the blank, and Γ\Gamma contains both Σ\Sigma and the blank. The start state is q0q_0 and the accepting and rejecting states are distinct. The transition amplitudes are given by δ:Q×Γ×Q×Γ×{L,R}→ℂ.\delta:Q\times\Gamma\times Q\times\Gamma\times\{L,R\}\to\mathbb C. The entry δ(q,a,q′,b,d)\delta(q,a,q',b,d) is the amplitude for changing from qq to q′q', writing bb over aa, and moving the head in direction dd. The induced global step must be unitary. For the computational model here we use efficiently approximable transition amplitudes.

    Suppose configuration CC has amplitude αC\alpha_C, internal state qq, and symbol aa under the head. A move to C′C' contributes αCδ(q,a,q′,b,d)\alpha_C\delta(q,a,q',b,d) to its new amplitude. Add the contributions from every predecessor of C′C' before taking a squared magnitude. Unitarity preserves ∑C|αC|2=1\sum_C|\alpha_C|^2=1.

    When do we measure?

    On input xx, start in q0q_0 with xx on the tape. In our fixed-time model we apply exactly T(|x|)T(|x|) transitions. At that time every configuration with nonzero amplitude must be accepting or rejecting. Measuring the internal state gives $$\Pr[M\text{ accepts }x]=\sum_{C:\,q(C)=q_{\rm acc}}|\alpha_C|^2.$$ Each application of the transition rule counts as one step regardless of how many configurations have amplitude. Before the designated measurement time, amplitude can leave configurations labeled accepting. Acceptance is determined at the final measurement.

    Definition (Bounded-error quantum time). A language is in BQTIME(f(n))\mathrm{BQTIME}(f(n)) if some QTM decides it in time T(n)=O(f(n))T(n)=O(f(n)), including the cost of determining when to measure. Members are accepted with probability at least 2/32/3 and nonmembers with probability at most 1/31/3. Quantum polynomial time is BQP=⋃k≥1BQTIME(nk).\mathrm{BQP}=\bigcup_{k\ge1}\mathrm{BQTIME}(n^k).

  2. Model equivalence & BQP

    Theorem (Model equivalence). Polynomial-time uniform, polynomial-size quantum circuits and polynomial-time quantum Turing machines decide the same languages with bounded error.

    From a circuit to a QTM

    Given input xx, the machine computes the description of C|x|C_{|x|} using the uniform circuit generator. It lays out input and work qubits on its tape and scans to the wires named by each gate. For HH or TT, it applies a one-qubit operation. For CNOT, it can coherently carry the control information to the target, perform the controlled flip, then undo the temporary storage. Measuring the control halfway through would destroy interference between its two alternatives.

    The tape region and gate list both have polynomial length. Even a full scan for every gate therefore costs only polynomial time. Measuring the output reproduces the circuit’s bounded-error decision.

    From a QTM to a circuit

    In T(n)T(n) steps, the machine visits at most O(n+T(n))O(n+T(n)) tape cells. Encode their symbols, the head location, and the internal state using qubits. Lay out one sequence of local circuit operations per simulated time step. The head moves at most one cell, so updates depend only on a bounded neighborhood. The simulation organizes these local operations reversibly to implement the global unitary, even when the head is in superposition. Repeating the step simulation T(n)T(n) times gives polynomial size, and the layout can be generated in polynomial time.

    Why gate approximation preserves bounded error

    A local unitary from the transition table may require approximation over {H,T,CNOT}\{H,T,\mathrm{CNOT}\}. First reduce the ideal computation’s error, say to 1/61/6, by independent repetition and majority vote. If the simulation uses KK local operations, approximating each to operator-norm error ε\varepsilon gives total operator error at most KεK\varepsilon. Choose inverse-polynomial precision so the change in acceptance probability is less than 1/61/6. The compiled circuit still succeeds with probability at least 2/32/3, with polynomial overhead.

  3. BQP in the complexity landscape

    Simulating classical randomness

    A deterministic polynomial-time machine is a randomized machine that uses no random bits, giving P⊆BPP\mathrm{P}\subseteq\mathrm{BPP}. To see BPP⊆BQP\mathrm{BPP}\subseteq\mathrm{BQP}, prepare a fresh H|0⟩H|0\rangle for every random bit and run a reversible simulation of the classical algorithm using those bits. Keep the random string in its own register. Distinct coin histories then occupy orthogonal states, so summing the final acceptance probabilities reproduces the classical algorithm’s success probability.

    Computing one amplitude in polynomial space

    Storing the entire state vector of a qq-qubit circuit takes 2q2^q entries. To prove BQP⊆PSPACE\mathrm{BQP}\subseteq\mathrm{PSPACE}, we can instead work backward through the circuit and recompute amplitudes as needed.

    Let A(i,y)A(i,y) denote the amplitude of basis string yy after gates U1,…,UiU_1,\ldots,U_i. For a desired output yy, apply the inverse of the last gate to its basis state: Ui†|y⟩=∑zcz|z⟩,cz=(Ui)y,z¯.U_i^\dagger|y\rangle=\sum_z c_z|z\rangle,\qquad c_z=\overline{(U_i)_{y,z}}. Each nonzero czc_z identifies a predecessor. The forward transition uses its complex conjugate, giving A(i,y)=∑z:cz≠0cz¯A(i−1,z).A(i,y)=\sum_{z:c_z\ne0}\overline{c_z}\,A(i-1,z).

    Recursive simulation and space bound 
    Amplitude(i, y):
    if i == 0:
        return 1 if y == initial_string else 0
    total = 0
    for (z, c) in nonzero terms of U[i]† |y⟩:
        total += conjugate(c) * Amplitude(i - 1, z)
    return total

Decide(x):
    generate the circuit for input length |x|
    initial_string = x followed by zeros on work wires
    probability = 0
    for each q-bit string y whose output bit is 1:
        probability += |Amplitude(m, y)|²
    return probability > 1/2

    An inverse Hadamard has two predecessors, an inverse TT has one with a phase, and a CNOT has one obtained by undoing the controlled flip. Each call inspects at most a 4×44\times4 local matrix. Depth-first evaluation keeps at most m+1m+1 calls active, each with a qq-bit string, gate index, and running sum. We also enumerate the final strings one at a time.

    For exact arithmetic, write ω=eiπ/4\omega=e^{i\pi/4}. After hh Hadamards, each amplitude is 2−h/22^{-h/2} times a sum of at most 2h2^h powers of ω\omega. Since ω8=1\omega^8=1, eight counts of O(h+1)O(h+1) bits suffice. Squaring amplitudes gives a common denominator 2h2^h, and adding at most 2q2^q terms needs at most qq more bits per coefficient. These real sums can be compared to 1/21/2 with polynomial space (equivalently, approximate to accuracy smaller than the 1/61/6 decision gap). The recursion may take exponential time, but its stack and arithmetic both use polynomial space.

    Where does NP fit?

    Neither NP⊆BQP\mathrm{NP}\subseteq\mathrm{BQP} nor BQP⊆NP\mathrm{BQP}\subseteq\mathrm{NP} is known. For example, a BQP algorithm for SAT would put all of NP in BQP by polynomial-time reduction. Shor’s algorithm alone establishes neither containment. Factoring asks for factors, while these classes are defined for decision problems.
