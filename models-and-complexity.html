  1. Quantum Turing machines

    Definition of a quantum TM

    Definition (Quantum Turing machine)

    A quantum Turing machine (QTM) M is a 7-tuple

    M = ( Q , Σ , Γ , δ , q 0 , q a c c , q r e j ) , M=(Q,\Sigma,\Gamma,\delta,q_0,q_{\mathrm{acc}},q_{\mathrm{rej}}),

    where

    • Q is a nonempty finite set of internal states.
    • Σ is a nonempty finite input alphabet that excludes the blank symbol ⊔.
    • Γ is a finite tape alphabet containing both Σ and the blank symbol ⊔.
    • q₀ ∈ Q is the initial state.
    • q a c c q_{\mathrm{acc}} , q r e j q_{\mathrm{rej}} ∈ Q are distinct states called the accepting state and the rejecting state, respectively.
    • δ is the transition amplitude function

    δ : Q × Γ × Q × Γ × { L , R } → ℂ . \delta:Q\times\Gamma\times Q\times\Gamma\times\{L,R\}\longrightarrow\mathbb C.

    If the machine is in state q and reads symbol a, then δ(q, a, q′, b, d) is the amplitude for entering state q′, writing symbol b, and moving the tape head in direction d.

    A configuration C specifies the internal state, the tape contents, and the head position. The machine can be in a superposition of configurations,

    | ψ ⟩ = ∑ C α C | C ⟩ , ∑ C | α C | 2 = 1 . \left\lvert \psi\right\rangle=\sum_C\alpha_C\left\lvert C\right\rangle,\qquad \sum_C|\alpha_C|^2=1.

    To apply the transition rule, consider each configuration C in the current superposition. Suppose C has amplitude α C \alpha_C , internal state q, and symbol a under its head. For each possible move (q′, b, d), let C′ be the configuration obtained by writing b, entering state q′, and moving the head in direction d. This move contributes amplitude α C \alpha_C δ(q, a, q′, b, d) to C′. The new amplitude of C′ is the sum of all contributions that reach it. Applying this rule to the entire superposition counts as one step. The transition table must induce a unitary transformation on the space of configurations. This ensures that the squared magnitudes of the configuration amplitudes still sum to 1. For the time bounds below, we assume the transition amplitudes can be approximated to b b bits in time polynomial in b b .

    To decide a language, we use a fixed running time T(n) for inputs of length n. On input x, the machine starts in state q₀ with x on its tape. After T(|x|) steps, we require that every configuration with nonzero amplitude has internal state q a c c q_{\mathrm{acc}} or q r e j q_{\mathrm{rej}} (otherwise the TM has not halted). We then measure the internal state. If α C \alpha_C is the final amplitude of configuration C, the acceptance probability is

    Pr [ M accepts x ] = ∑ C : q ( C ) = q a c c | α C | 2 , \Pr[M\text{ accepts }x]=\sum_{C:\,q(C)=q_{\mathrm{acc}}}|\alpha_C|^2,

    where q(C) denotes the internal state of C.

    In this model, q a c c q_{\mathrm{acc}} and q r e j q_{\mathrm{rej}} are not sink states as they are in the usual classical model. During the computation, the probability of observing the accepting state can therefore decrease.

    Quantum TM running time

    Naturally, we can define the running time of a quantum Turing machine by counting how many times it applies its transition rule. In our fixed-time model, the algorithm specifies a function T : N → N. On every input x of length n, the machine takes exactly T(n) steps, measures its internal state, and halts. Each application of the transition rule counts as one step, even when the machine is in a superposition of many configurations.

    Definition (Bounded-error quantum time)

    A language L belongs to BQTIME(f(n)) if there exists a quantum Turing machine M that runs in time T(n) = O(f(n)) and decides L with bounded error. That is, for every input x,

    x ∈ L ⟹ Pr [ M accepts x ] ≥ 2 3 , x ∉ L ⟹ Pr [ M accepts x ] ≤ 1 3 . x\in L\implies \Pr[M\text{ accepts }x]\ge\tfrac23,\qquad x\notin L\implies\Pr[M\text{ accepts }x]\le\tfrac13.

    Here the time bound includes the cost of keeping track of when to measure.

    The polynomial-time version of BQTIME coincides with the circuit-based class BQP defined earlier. We explain this equivalence in chapter 4.

    Definition (BQP via quantum Turing machines)

    BQP is the class of languages that a quantum Turing machine can decide in polynomial time with bounded error. Equivalently,

    B Q P = ⋃ k = 1 ∞ B Q T I M E ( n k ) . \mathrm{BQP}=\bigcup_{k=1}^\infty\mathrm{BQTIME}(n^k).

  2. Model equivalence & BQP

    The equivalence of the two definitions of BQP, denoted B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} and B Q P T M \mathrm{BQP}_{\mathrm{TM}} in this chapter, is not immediate. We sketch both inclusions below.

    1. Simulating quantum circuits with a quantum Turing machine

    Inclusion to prove: B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} ⊆ B Q P T M \mathrm{BQP}_{\mathrm{TM}} .

    Let L be a language such that L ∈ B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} . We therefore know we can create the quantum circuit that solves L in polynomial time with bounded error since B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} covers polynomial-time uniform circuits. Now our QTM can first create the circuit in polynomial time. Then it can create a scratchpad with the input and work qubits and simulate the circuit. Applying a quantum gate takes at most linear time in the number of qubits, which is polynomial in the input length. We scan the tape to locate the required qubits and apply the corresponding operation—keeping the tape-head trajectory synchronized across all superposition branches so that configurations with the same wire contents interfere properly. H and T act directly on a single qubit. For CNOT we can have the TM simultaneously enter one of two internal states depending on the value of the control qubit, modify the target bit differently depending on which of the two states it is in, and then uncompute the temporary copy of the control.

    Circuit evaluation takes polynomial time because there are polynomially many gates and each takes polynomial time to simulate. The simulation preserves the circuit’s bounded-error guarantee, so L ∈ B Q P T M \mathrm{BQP}_{\mathrm{TM}} .

    2. Simulating a quantum Turing machine with quantum circuits

    Inclusion to prove: B Q P T M \mathrm{BQP}_{\mathrm{TM}} ⊆ B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} .

    This proof is nearly identical to efficient TM to circuit and we in fact we will use the same kind of grid. Let L be a language such that L ∈ B Q P T M \mathrm{BQP}_{\mathrm{TM}} , so it has a polynomial time bound T(n). We can boost the QTM so that its success probability is at least 3/4. To simulate it with a uniform quantum circuit family, we represent the tape and head position across the n + T(n) reachable cells using registers of qubits which contain a state option and work tape character. Because each QTM transition only modifies the cell under the head and moves the head by at most one position, one global QTM step can be decomposed into a polynomial number of local unitary operators acting on constant-size windows of adjacent cells (preserving unitarity without copying quantum states). We also only have a grid of size T(n) * (n + T(n)) so our number of transition gates is also polynomial. Unlike in the classical case, transfer function can have arbitrary complex entries that cannot be realized exactly by finitely many {H, T, CNOT} gates. However, if there are M = poly(n) local unitary blocks in total, we can approximate each block to error O(1/M) using polylog(M) = polylog(n) gates from {H, T, CNOT} via the Solovay–Kitaev theorem. Summing the errors across all M blocks changes the final acceptance probability by less than 1/12, keeping it at least 2/3 (or at most 1/3) in polynomial circuit size. Thus L ∈ B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} .

    Combining the two inclusions gives B Q P G a t e \mathrm{BQP}_{\mathrm{Gate}} = B Q P T M \mathrm{BQP}_{\mathrm{TM}} .

  3. BQP in the complexity landscape

    We now examine how BQP fits into the complexity hierarchy and what this tells us about the power of efficient quantum computation.

    P ⊆ BPP ⊆ BQP

    It suffices to show that BPP ⊆ BQP. Let L ∈ BPP. There is a randomized algorithm with a polynomial time bound T(n) whose success probability, over its random choices, is at least 2/3 for every input x. To simulate this algorithm, a quantum circuit (or QTM) prepares an equal superposition H | 0 ⟩ = ( | 0 ⟩ + | 1 ⟩ ) / 2 H\left\lvert 0\right\rangle=(\left\lvert 0\right\rangle+\left\lvert 1\right\rangle)/\sqrt{2} for each random coin flip, keeping each random bit on a fresh ancilla wire so different random choices never interfere. After simulating T(n) steps reversibly, we measure the output. The success probability is still at least 2/3, so L ∈ BQP.

    BQP ⊆ PSPACE

    While it might be immediately clear that BQP ⊆ EXP since one could just keep track of every possible configuration’s amplitude and perform updates (this is one way people simulate quantum computers in the real world), it might be surprising to see that BQP ⊆ PSPACE. The idea is that we compute one amplitude at a time by working backward through the circuit.

    Let L ∈ BQP. Given an input x, we know that in polynomial time we can generate a circuit of polynomial size C | x | C_{|x|} . Suppose the circuit has q qubits and applies the gates G₁,…, Gₘ in order, where q and m are polynomially bounded in the input length. Let A(i, y) be the amplitude of the basis state |y⟩ after the first i gates. We will compute one amplitude at a time by working backward through the circuit.

    Suppose we want to compute A(i, y). Write U i U_i for the matrix of gate G i G_i . Here y is the output basis string whose amplitude we want after gate i, and z ranges over the q-bit basis strings immediately before gate i. We write Uᵢ† for the conjugate transpose of Uᵢ, obtained by transposing the matrix and taking the complex conjugate of each entry. Because the gate is unitary, Uᵢ† = Uᵢ⁻¹. Apply this inverse gate to |y⟩ to identify the preceding basis states that can contribute to its amplitude:

    U i † | y ⟩ = ∑ z c z | z ⟩ , c z = ( U i ) y , z ¯ . U_i^\dagger\left\lvert y\right\rangle=\sum_z c_z\left\lvert z\right\rangle,\qquad c_z=\overline{(U_i)_{y,z}}.

    Thus each nonzero c z c_z identifies a basis state |z⟩ that can contribute to |y⟩ through the forward gate Uᵢ. Its contribution is its previous amplitude A(i − 1, z) multiplied by the forward transition amplitude ( U i ) y , z = c z ¯ (U_i)_{y,z}=\overline{c_z} . Summing these contributions gives

    A ( i , y ) = ∑ z ( U i ) y , z A ( i − 1 , z ) = ∑ z : c z ≠ 0 c z ¯ A ( i − 1 , z ) . A(i,y)=\sum_z (U_i)_{y,z}A(i-1,z)=\sum_{z:c_z\ne0}\overline{c_z}A(i-1,z).

    This gives the following recursive algorithm. 
    Amplitude(i, y):
    if i == 0:
        return 1 if y equals the initial basis string, else 0

    total = 0
    for each nonzero term (z, c) in inverse(U[i]) applied to |y>:
        total = total + conjugate(c) * Amplitude(i - 1, z)
    return total

Decide(x):
    generate the circuit for inputs of length |x|
    initial basis string = x followed by zeros for the work qubits
    accept_probability = 0
    for each q-bit string y whose output bit is 1:
        accept_probability += |Amplitude(m, y)|^2
    return accept_probability > 1/2

    We see that each gate acts on at most two qubits, so to list the terms of Uᵢ† |y⟩ we only need to inspect a matrix of size at most 4 × 4. All other bits of y stay fixed. We evaluate the recursive calls one at a time and reuse their workspace. Thus, even if the recursion makes exponentially many calls in total, at most m + 1 calls are active at once. Each active call stores a q-bit string, a gate index, and a running sum.

    It remains to account for the space needed by the numbers themselves. After h Hadamard gates, each amplitude is 2 − h / 2 2^{-h/2} times a sum of at most 2ʰ powers of ω. Since ω⁸ = 1 (and −1 = ω⁴, so every computational path contributes a single power of ω), we can store this sum exactly by counting how many times each of the eight powers occurs. Each non-negative count takes only O(h + 1) bits. The squared amplitudes all have the same denominator 2ʰ at the final layer, and summing over at most 2 q 2^q output strings adds at most q bits to the size of their integer coefficients. Thus the running sums also fit in polynomial space.

    BQP versus NP

    The relationship between NP and BQP remains unresolved. They are conjectured to be incomparable; in particular, SAT is conjectured not to belong to BQP.
